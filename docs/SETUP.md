# دليل الإعداد والتشغيل

## iOS App (للمشرف)

### المتطلبات
- Xcode 15+
- iOS 17+
- macOS 14+

### خطوات البدء

1. **افتح المشروع في Xcode:**
```bash
open iOS/InvestTracker.xcodeproj
```

2. **حدد الـ Signing Team** في Project Settings

3. **شغّل على جهازك** (Simulator أو Device)

### أول تشغيل
- التطبيق يُنشئ قاعدة البيانات تلقائياً عند أول تشغيل
- يطلب إذن الإشعارات لتذكيرات الزكاة والدفعات
- يبدأ تحديث الأسعار تلقائياً عند وجود إنترنت

---

## Web Backend (بوابة الأعضاء)

### المتطلبات
- Python 3.11+
- pip

### التثبيت

```bash
cd backend
pip install -r requirements.txt
```

### التشغيل

**محلياً للتطوير:**
```bash
cd backend
python app.py
```
التطبيق يعمل على: `http://localhost:5000`

**للإنتاج على الشبكة المنزلية:**
```bash
cd backend
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### متغيرات البيئة

```bash
# مسار قاعدة البيانات (من التطبيق iOS)
export DB_PATH="~/Library/Containers/com.investtracker.app/Data/Documents/invest_tracker.sqlite"

# مفتاح الجلسة (غيّره في الإنتاج)
export SECRET_KEY="your-secret-key-here"

# المنفذ (اختياري)
export PORT=5000
```

### قاعدة البيانات التجريبية
عند عدم وجود قاعدة بيانات، يُنشئ النظام بيانات تجريبية تشمل:
- صندوق تجريبي باسم "صندوق العائلة الاستثماري"
- 3 أعضاء بأعداد وحدات مختلفة
- رموز وصول تجريبية: `123456`, `234567`, `345678`

## ربط iOS بالـ Backend

1. شغّل الـ Backend على نفس شبكة الـ WiFi
2. في التطبيق iOS: **الإعدادات → بوابة الويب → رابط بوابة الأعضاء**
3. أدخل: `http://[IP-جهازك]:5000`
4. الأعضاء يدخلون من هواتفهم على نفس الرابط

للوصول من خارج المنزل: استخدم ngrok أو Tailscale مجاناً.

---

## إعداد أول صندوق

1. افتح التطبيق iOS
2. اذهب لـ **الصناديق** → **+ إنشاء صندوق**
3. أدخل اسم الصندوق وقيمة الوحدة الشهرية
4. أضف الأعضاء مع أعداد وحداتهم
5. فعّل الوصول للويب لكل عضو → شارك رمز الوصول معه

---

## إضافة العمليات الاستثمارية

**طريقة 1: عبر الصورة (موصى بها)**
1. المحفظة → + إضافة عملية → صورة
2. التقط صورة الإيصال/الرسالة البنكية
3. راجع البيانات المستخرجة تلقائياً
4. أكد الحفظ

**طريقة 2: إدخال يدوي**
1. المحفظة → + إضافة عملية → يدوي
2. اختر نوع العملية (شراء/بيع/إيداع...)
3. أدخل التفاصيل

**طريقة 3: Excel**
1. نزّل القالب من الإعدادات
2. أدخل البيانات
3. ارفع الملف

---

## احتساب الزكاة

1. اذهب لـ **الزكاة**
2. تحقق أن الأسعار محدّثة (اضغط تحديث)
3. اضغط **احتساب الزكاة الشخصية**
4. راجع الوعاء والمبلغ المستحق
5. بعد الإخراج: اضغط **أخرجت الزكاة**

## ملاحظات أمنية

- قاعدة البيانات في مسار محمي داخل Sandbox التطبيق
- الـ Backend للقراءة فقط - لا يمكن للأعضاء تعديل أي شيء
- رموز الوصول من 6 أرقام - يمكن تجديدها من الإعدادات
- يُنصح بتشغيل الـ Backend على شبكة WiFi خاصة فقط
