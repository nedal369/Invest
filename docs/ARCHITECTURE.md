## حساب الزكاة

```
وعاء الزكاة = قيمة الأصول التي حال حولها
             + الكاش الذي حال حوله
             + توزيعات الأرباح

النصاب = 85 غرام × سعر الذهب 24K
الحول = 354.37 يوم (قمري)
نسبة الزكاة = 2.5%

زكاة مستحقة = وعاء الزكاة × 2.5% (إذا بلغ النصاب)
```

## صناديق الاستثمار - نظام الوحدات

```
NAV الوحدة = إجمالي قيمة الصندوق ÷ إجمالي الوحدات

نصيب العضو = (وحداته ÷ إجمالي وحدات الصندوق) × إجمالي القيمة

زكاة العضو = نصيبه من الوعاء × 2.5%
```

## القروض الحسنة

```
الشروط:
  - الحد الأعلى = اشتراك العضو السنوي
  - المدة = 12 شهر
  - بدون فائدة (قرض حسن)
  - القسط = المبلغ ÷ 12

القسط يبدأ من الشهر التالي للصرف
```
